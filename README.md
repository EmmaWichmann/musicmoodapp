# Music Mood App

A front-end web app for saving songs by mood.

## Current Status

This is an early learning project built while practicing `HTML`, `CSS`, and `JavaScript`.

## What It Does

- lets a user choose a mood
- enter a song
- optionally add an artist and note
- save an entry
- update the page with user input

## What I Practiced

- structuring a page with `HTML`
- styling with `CSS`
- handling button clicks with `JavaScript`
- finding elements with `document.getElementById()`
- reading user input with `.value`
- updating visible text with `textContent`

## Next Steps

- display saved entries more clearly
